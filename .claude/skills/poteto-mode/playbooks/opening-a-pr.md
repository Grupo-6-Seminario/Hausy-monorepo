# PR delivery

Read `docs/agents/workflow.md` and the task's scoped instructions first.

Return verified local changes unless the user explicitly invoked `ship`. On that invocation, the `ship` skill alone creates or updates the PR. Keep a useful GitHub-renderable diagram and evidence in the body; do not invoke an alternate PR publisher.

Complete when the requested result has direct evidence and unresolved limits are reported. Keep outputs local under the shared authorization rules.
