# Bug fix

Read `docs/agents/workflow.md` and the task's scoped instructions first.

Use `diagnosing-bugs` to execute a red-capable reproduction, minimize it, test hypotheses, and repair the owner. Verify the intended failure is gone, audit touched tests, and remove temporary instrumentation. Ambiguous intended behavior returns to the user.

Complete when the requested result has direct evidence and unresolved limits are reported. Keep outputs local under the shared authorization rules.
