# Worktree cleanup

Read `docs/agents/workflow.md` and the task's scoped instructions first.

Inventory worktrees, size, merge state, uncommitted files, and active use before proposing cleanup. Protect project data and all unrelated changes. Show the exact deletion targets and obtain explicit approval before deletion. Never infer deletion permission from a disk-space question.

Complete when the requested result has direct evidence and unresolved limits are reported. Keep outputs local under the shared authorization rules.
