# Arena

Define the common brief, exclusions, observable acceptance criteria, and comparison criteria before generating alternatives. Use isolated local outputs. Follow `docs/agents/workflow.md` for approval and delegation limits.

Produce two or three materially different approaches, using the parent and sequential work by one independent agent where useful. Do not create a fleet, nested delegates, or unsupported model requests. Examine every output directly. Judge correctness, simplicity, user outcome, and actual evidence on the same criteria.

Choose a base and incorporate only compatible strengths that improve the agreed result. Verify the combined artifact rather than trusting candidate reports. Explain the consequential tradeoff briefly. Done when the selected approach meets the approved criteria. Publishing belongs to explicitly invoked `ship`.
