# Figure it out

Define the observable done predicate, exclusions, risks, and verification plan. Follow feature approval and authorization boundaries in `docs/agents/workflow.md`. Build a task-specific sequence of coherent units, each ending in a check.

Use existing scripts or build a small rerunnable tool when repeated manual work would be less reliable. Keep a local decision trail through `show-me-your-work`. Delegate only bounded scopes within the shared budget. Stop speculative work that does not advance the approved predicate.

Verify the actual final artifact, review substantial code normally, and report executed proof and blockers. A long-task request authorizes persistence within scope, not commits, publishing, deployment, or altered acceptance criteria.
