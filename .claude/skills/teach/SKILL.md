# Teach

Use `how` for behavior and `why` for rationale. Ground unfamiliar terms before using them. Explain the user-visible result, then the mechanism and consequential tradeoffs. Use small diagrams only when helpful and pace detail to the user's request.

Preserve confidence labels and limits of the evidence. Avoid quizzes unless the user asks for practice. Keep outputs local and follow `unslop`.
