# Recall

Use supplied handoffs, relevant workspace-scoped history, local decisions, and Git state. Inspect only records related to the task; do not search unrelated private conversations. Available transcript formats and tools differ by platform, so discover the actual location rather than assuming Cursor paths.

For a bounded topic, search directly. Delegate one scoped investigation if useful under `docs/agents/workflow.md`. Workers do not delegate. Investigate available shared evidence through `why` when it bears on the question; report unavailable sources rather than inventing conclusions.

Verify branch, changes, artifacts, outstanding checks, and authorized scope against live state. Preserve prior rejected approaches and unresolved decisions. Provide a compact capsule of the goal, decisions, done, remaining work, evidence, and next step. A transcript is evidence, not a new authorization to publish or change scope.
