# How

Trace the real entry point through callers, domain decisions, adapters, and observable output. Inspect code and run a focused observation when needed. Delegate one bounded read-only investigation if useful; follow `docs/agents/workflow.md`.

Explain the flow in plain language with concrete code anchors. Use `show-me` only if a diagram makes it easier to understand. Separate observed behavior from inference and unknowns. Done when the requested behavior and its owner are explained with supporting evidence. Keep investigation separate from unrequested implementation.
