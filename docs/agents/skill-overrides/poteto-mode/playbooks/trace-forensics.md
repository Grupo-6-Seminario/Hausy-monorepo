# Captured trace diagnosis

Read `docs/agents/workflow.md` and the task's scoped instructions first.

Inspect the supplied trace or profile, its capture conditions, and relevant code. Reduce it to the causal path rather than incidental activity. Label what the capture proves and what needs a live reproduction. Deliver diagnosis without unrequested fixes.

Complete when the requested result has direct evidence and unresolved limits are reported. Keep outputs local under the shared authorization rules.
