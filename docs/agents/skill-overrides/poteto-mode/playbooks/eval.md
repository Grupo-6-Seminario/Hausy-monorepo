# Agent behavior evaluation

Read `docs/agents/workflow.md` and the task's scoped instructions first.

Define observable criteria before running and keep that rubric outside the candidate workspace. Use an isolated project-shaped workspace and an organic user request. Do not tell the candidate it is under evaluation or explicitly ask it to read instructions. Start a fresh session without the authoring conversation. Run one candidate at a time under the shared delegation limit. Inspect actual file reads, tool actions, outputs, and artifact changes; self-reported compliance is insufficient. Report failures, repair instructions, and rerun affected branches. Paid external evaluations require approval.

Complete when the requested result has direct evidence and unresolved limits are reported. Keep outputs local under the shared authorization rules.
