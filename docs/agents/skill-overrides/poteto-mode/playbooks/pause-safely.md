# Pause safely

Read `docs/agents/workflow.md` and the task's scoped instructions first.

When the user asks to pause, stop implementation and write a local handoff with original goal, done, remaining work, verification, active resources, and next command. Clean up only resources you created when appropriate. Do not commit or publish as part of pausing.

Complete when the requested result has direct evidence and unresolved limits are reported. Keep outputs local under the shared authorization rules.
