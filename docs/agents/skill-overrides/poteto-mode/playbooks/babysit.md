# PR inspection

Read `docs/agents/workflow.md` and the task's scoped instructions first.

For a supplied PR, inspect status, checks, diff, and findings. Assess bot comments skeptically from evidence. Report actionable issues and fix only authorized scope. Reading PR status does not authorize posting comments, pushing, merging, or installing a paid review service. Use `ship` only when explicitly invoked.

Complete when the requested result has direct evidence and unresolved limits are reported. Keep outputs local under the shared authorization rules.
