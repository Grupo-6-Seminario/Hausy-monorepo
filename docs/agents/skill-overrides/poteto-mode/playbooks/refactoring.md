# Refactoring

Read `docs/agents/workflow.md` and the task's scoped instructions first.

Pin observable behavior and an actual verification boundary. Make small behavior-preserving changes, checking each coherent unit. Prefer deletion and simpler ownership. If a feature or bug emerges, report it separately. Review equivalence and useful comments; leave changes local.

Complete when the requested result has direct evidence and unresolved limits are reported. Keep outputs local under the shared authorization rules.
