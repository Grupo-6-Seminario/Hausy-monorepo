# Bounded multi-phase coordination

Read `docs/agents/workflow.md` and the task's scoped instructions first.

Plan a large program as sequential coherent units with explicit inputs, owners, and done predicates. Keep one concurrent subagent and no nested delegation. Isolate writes and verify every result before integration. Keep reports and artifacts local; each publication or deployment remains separately authorized.

Complete when the requested result has direct evidence and unresolved limits are reported. Keep outputs local under the shared authorization rules.
