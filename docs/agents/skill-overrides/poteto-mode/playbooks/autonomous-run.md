# Autonomous local run

Read `docs/agents/workflow.md` and the task's scoped instructions first.

Agree the done predicate, exclusions, approval gates, budget, and evidence. Drive coherent verified units within that scope, keeping a local decision trail. Pause only dependent work for unresolved human decisions while progressing independent work. Continue until the predicate is proven or a concrete blocker prevents progress; report blockers without claiming completion.

Complete when the requested result has direct evidence and unresolved limits are reported. Keep outputs local under the shared authorization rules.
