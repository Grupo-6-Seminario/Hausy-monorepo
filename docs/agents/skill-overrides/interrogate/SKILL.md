# Interrogate

Pin the intent, constraints, artifact revision, and questions that would falsify the approach. Have the parent and one independent reviewer use the same brief. Different perspectives may run sequentially within `docs/agents/workflow.md` delegation limits.

Seek the strongest counterargument and evidence that could refute the decision. Preserve disagreements and identify the premise behind them. Categorize findings as actionable, worth considering, noted, or dismissed with reasons. Keep review input distinct from approved specification. Do not automatically fix, publish, or expand scope.
