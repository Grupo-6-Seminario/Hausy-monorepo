# Automate me

Locate any existing project-local mode and inspect only relevant workspace history or the supplied session. Collect repeated preferences with evidence, then interview the user about unresolved decisions. Do not generalize one correction into an unsupported standing preference.

Use `writing-for-agents` to draft a minimal project-local mode with explicit triggers and links to existing workflows. Apply `unslop`. Show the draft and wait for approval before applying it. Keep global/shared installations untouched unless separately authorized.

Verify that triggers and rules match the approved preferences. Leave local changes and a concise report. The skill does not publish issues, send messages, commit, push, or create PRs.
